How it works

Three checks. No CAPTCHA. No API calls a user can see.

Each one catches a different kind of bot, and they run in order — cheapest first, so most spam never gets past step one.

01 — Honeypot field

A field bots can't resist

An invisible input is added to your form. Real visitors never see it or fill it in. Bots that auto-fill every field trip it instantly.

02 — Timing check

Humans take longer than 400ms

Formcatch times the gap between page load and form submit. Scripted submissions happen in milliseconds — no person types that fast.

03 — Rate limiting

One submission per visitor, per window

Repeated bursts from the same source get throttled automatically, stopping the flood before it starts.

Live in under two minutes

Drop one script tag before your closing </body> and add one attribute to your form. That's the entire integration — no backend changes, no dashboard setup required to start.

<!-- 1. Add before </body> -->
<script src="https://cdn.formcatch.dev/v1.js" data-site="your-site-id"></script>

<!-- 2. Mark your existing form -->
<form data-formcatch action="/submit">
